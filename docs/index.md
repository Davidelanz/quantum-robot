``quantum-robot`` is a Python package for quantum-like perception modeling for robotics.
The package exploits <a href="https://qiskit.org/">Qiksit</a> framework, implementing the models on
quantum circuits which can be simulated on a classical computer or sent to a quantum
backend (service provided by <a href="https://quantum-computing.ibm.com/">IBM Quantum Experience</a>).
